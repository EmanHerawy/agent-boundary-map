Agent Trust Map

See where your agent puts its trust

For teams that build or configure an agent, on their own code or on a harness such as Claude Code or Codex. Answer questions about how it works, and get a report of every trust boundary: who holds it (you, the harness, a service or a person), and whether it holds outside the model or only while the model behaves.

  • You only see steps for the parts your agent has. Each answer is read for the least protected route.
  • The report opens with the routes untrusted input could take: can one injected message make the agent read sensitive information and send it out, or change things?
  • No evidence to upload. "Don't know" is a fine answer; it shows you what to find out.

The questions changed, so answers saved from the earlier version were cleared.
